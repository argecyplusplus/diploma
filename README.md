# Разработка приложения для моделирования испытаний газотермических покрытий лопаток газотурбинных двигателей

Программный комплекс для расчета процесса формирования и свойств порошковых покрытий лопаток газотурбинных двигателей. Система объединяет геометрическое построение, расчет аэродинамики в FreeFem++ и тепловой анализ на Python.

## Технические требования
* **ОС:** Windows 10/11, Linux
* **Python:** 3.12
* **FreeFem++:** v4.15 (должен быть установлен по пути `C:\Program Files (x86)\FreeFem++\FreeFem++.exe`, в настройках программы можно будет изменить)
* **Flask:** 3.0.3

## Структура проекта
Будет дополнена

## Запуск программы

### 1. Подготовка окружения
Убедитесь, что вы находитесь в корневой директории проекта (команда cd).

Далее создайте виртуальное окружение и установите в него все зависимости:
```bash
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
```
### 2. Настройка путей
Если путь к FreeFem++ отличается от стандартного ```C:\Program Files (x86)\FreeFem++\FreeFem++.exe```, необходимо настроить путь к нему в настройках приложения

### 3. Запуск приложения
```bash
python run.py
```

После запуска откройте браузер и перейдите по адресу из консоли, например, http://127.0.0.1:5000
