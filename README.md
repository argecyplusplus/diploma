# Приложение для моделирования испытаний газотермических покрытий лопаток газотурбинных двигателей

Веб-приложение для параметрического моделирования, аппроксимации и прочностного анализа лопаток газотурбинных двигателей на базе FreeFEM++.

## Технические требования

- **ОС:** Windows 10/11, Linux
- **Python:** 3.12
- **FreeFem++:** v4.15 (стандартный путь: `C:\Program Files (x86)\FreeFem++\FreeFem++.exe`)
- **Flask:** 3.0.3

## Структура проекта

```
diploma/
├── app/                    # Основной код приложения
│   ├── controllers/        # Маршруты и обработчики запросов
│   ├── models/             # Модели базы данных (SQLAlchemy)
│   ├── services/           # Бизнес-логика
│   ├── templates/          # HTML-шаблоны
│   ├── static/             # CSS, JS, изображения
│   └── utils/              # Вспомогательные утилиты
├── databases/              # Файлы баз данных SQLite
├── uploads/                # Папка с результатами расчётов
├── requirements.txt        # Зависимости Python
└── run.py                  # Точка входа
```

## Запуск программы

### 1. Установка зависимостей

```bash
python -m venv venv
.\venv\Scripts\activate          # Windows
source venv/bin/activate         # Linux/Mac
pip install -r requirements.txt
```

### 2. Настройка FreeFem++

При первом запуске укажите путь к `FreeFem++.exe` в настройках приложения, если он отличается от стандартного.

### 3. Запуск

```bash
python run.py
```

Откройте браузер по адресу: http://127.0.0.1:5000
